# Contribution Guidelines

Contributions are welcome. This list is a curation of useful startup tools, so please keep entries focused and high quality.

## Adding an item

1. Search the list first. If the tool is already included, improve the existing entry instead of adding a duplicate.
2. Add a tool only when you can recommend it and it is actively maintained.
3. Use this format: `- [Name](https://example.com) - Short description.`
4. Link to the tool's own site. Do not use placeholders, shorteners, or affiliate tracking links.
5. Start the description with an uppercase letter and end it with a period.
6. Put the item in the matching category, using the same style as the surrounding entries.
7. Check spelling and grammar.
8. Open a pull request and explain why the tool belongs on the list.

## Updating a pull request

If a maintainer asks for changes, update the existing pull request rather than opening a new one.
